# Aynite Batteries

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Community-contributed extensions for [Aynite](https://github.com/w-t-yang/aynite) — skills, commands, dataviews, fileviews, and more.

---

## What's Inside

| Category | Description |
|----------|-------------|
| **Commands** | Deterministic scripts you can run from the AI chat with `>` |
| **Skills** | AI-guided workflows invoked with `/` |
| **Dataviews** | Custom visualization views |
| **Fileviews** | Custom file renderers |

More will be added over time. Contributions welcome!

---

## Installation

Clone the repo and point Aynite to the relevant folders:

```bash
git clone https://github.com/w-t-yang/aynite-batteries.git
```

Then in **Aynite Settings → Skills / Commands**, add the corresponding subdirectory paths from this repo.

Contributions are welcome! If you'd like to add a skill, command, dataview, or fileview, feel free to open a pull request.
